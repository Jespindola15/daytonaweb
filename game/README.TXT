(Installation)
1. Insert the CD-ROM in the CD drive.
2. This starts the installation program automatically.
Please follow on screen instruction after the program starts.
3. Consult the Help file concerning game play methods.


(Note)
If the installation program didn't start automatically, please start it manually.
Do not load the installation program while playing the game.
Please pause the game, when you open the Help or minimize the game.
To play DAYTONA USA, your peripheral devices must all be compatible with DIRECT X2.
Your screen must be set to 16-bit color when playing DAYTONA USA.
The Help File screens are still under construction.
You need an nV compatible board if you want to use the Saturn Control Pad or
Saturn Racing Controller. If you don't have an nV compatible board, you can
use your keyboard or a PC pad to play the game.
